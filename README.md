## 🚀 Getting Started

Clone the repo and install dependencies:

```bash
git clone https://github.com/niteshchauhan0/SwipeDeck.git
cd SwipeDeck
npm install
```

Run the app:
```bash
npm start
```
or for bare RN:
```bash
npx react-native run-ios
npx react-native run-android
```
